# Phase 8. 납품

## 목적
최종 제출물을 정리하고, 제출 전 점검을 수행한다.

## 제출 전 점검 프롬프트

```
제출 전 최종 점검을 수행해줘.

점검 항목:
1. 서버 실행 확인: 서버가 정상 기동되는가?
2. 필수 기능 동작: requests.md의 필수 기능(P1~Pn)이 모두 동작하는가?
3. 인수 테스트 통과: 고객의 인수 테스트 항목이 모두 통과하는가?
4. 코드 정리: 불필요한 console.log, 주석, 미사용 코드가 남아 있지 않은가?
5. 환경변수: API 키 등 민감 정보가 코드에 하드코딩되어 있지 않은가?
6. README: 실행 방법, 기술 스택, 프로젝트 구조가 명시되어 있는가?
7. .gitignore: node_modules, .env 등이 포함되어 있는가?
8. 저장 상태: 모든 파일이 저장되어 있는가?
```

## README 작성 프롬프트

```
프로젝트 README.md를 작성해줘.

포함할 내용:
- 프로젝트 개요 (한 줄 설명)
- 기술 스택
- 프로젝트 구조 (tree)
- 실행 방법 (환경변수 설정, 설치, 실행 명령어)
- 주요 기능 설명
- API 명세 요약
```

## 납품 보고 프롬프트

```
고객에게 최종 납품 보고 메시지를 작성해줘.

포함할 내용:
- 완성된 기능 요약
- 서비스 실행 방법
- 알려진 제한사항
- 인수 테스트 결과 요약
```
