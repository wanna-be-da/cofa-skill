# Phase 6. 단위 테스트

## 목적
구현된 각 기능이 개별적으로 올바르게 동작하는지 검증한다.

## 테스트 범위
- API 엔드포인트별 요청/응답 검증
- 데이터 모델 CRUD 동작 검증
- 인증/권한 분기 검증
- 에러 케이스 (잘못된 입력, 미인증 접근 등)

## 실행 프롬프트

```
현재 구현된 기능에 대한 단위 테스트를 작성해줘.

테스트 대상:
- [테스트할 모듈/API 명시]

테스트 조건:
- 정상 케이스와 에러 케이스를 모두 포함
- 테스트 실행 명령어를 알려줘
- 실패하는 테스트가 있으면 원인 분석 후 수정해줘
```

## 전체 테스트 실행 프롬프트

```
전체 단위 테스트를 실행하고, 결과를 요약해줘.
실패 항목이 있으면 원인을 분석하고 수정해줘.
```
