# Phase 3. 요구사항 합의

## 목적
작성된 요구사항 정의서를 고객과 재확인하여 누락/오해를 방지한다.

## 합의 체크리스트

고객 DM으로 아래 항목을 확인한다.

```
요구사항 정의서를 작성했습니다. 아래 항목을 확인 부탁드립니다.

1. [서비스 목적] ~가 맞나요?
2. [필수 기능] 우선순위가 다음과 같은데, 조정이 필요한 부분이 있나요?
   - P1: ...
   - P2: ...
   - P3: ...
3. [데이터] 다루는 데이터 항목에 누락된 것이 있나요?
4. [화면 구성] 메인 / 서브 페이지 구성이 이대로 괜찮나요?
5. [인수 테스트] 납품 시 확인할 시나리오가 다음과 같은데, 추가할 항목이 있나요?
6. [제약 조건] 보안/금지 사항 외 추가 주의사항이 있나요?
```

## 합의 후 처리

- 변경 사항이 있으면 requests.md를 업데이트
- 합의 완료 후 다음 Phase(개발 Plan)로 진행

## 실행 프롬프트

```
고객에게 요구사항 합의를 요청한 결과, 아래와 같은 피드백을 받았다.
이를 반영하여 requests.md를 업데이트해줘.

[피드백 내용]
```
