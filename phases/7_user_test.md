# Phase 7. 사용자 테스트 (UAT)

## 목적
고객의 인수 테스트 항목 기준으로 전체 서비스를 E2E 검증한다.

## 실행 프롬프트

```
requests.md의 인수 테스트 항목을 기준으로 사용자 테스트를 수행해줘.

절차:
1. 서버를 실행한다.
2. 인수 테스트 시나리오를 하나씩 수행한다.
3. 각 시나리오의 통과/실패 여부를 기록한다.
4. 실패 항목이 있으면 원인을 분석하고 수정한다.
5. 수정 후 재검증하여 전체 통과를 확인한다.

결과를 아래 형식으로 정리해줘:
| 시나리오 | 수행 절차 | 기대 결과 | 실제 결과 | 통과 여부 |
```

## 고객 DM 보고 프롬프트

```
사용자 테스트 결과를 고객에게 보고할 메시지를 작성해줘.

포함할 내용:
- 테스트 시나리오별 결과 요약
- 발견된 이슈와 조치 사항
- 서비스 실행 방법
- 추가 확인이 필요한 부분
```
