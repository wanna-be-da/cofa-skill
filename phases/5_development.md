# Phase 5. 개발

## 목적
개발 TODO에 따라 순차적으로 기능을 구현한다.

## 개발 진행 원칙
- TODO 항목 하나를 완료할 때마다 커밋
- 기능 단위로 동작 확인 후 다음 항목 진행
- 외부 API가 미제공이면 Mock부터 구현하고 비즈니스 로직을 연결

## 기능 구현 프롬프트 (반복 사용)

```
개발 TODO에서 [항목명]을 구현해줘.

구현 조건:
- requests.md의 관련 요구사항을 충족할 것
- 개발 계획서의 API 설계 / 데이터 모델을 따를 것
- 기존 코드와 일관된 패턴을 유지할 것
- 구현 완료 후 동작 확인 방법을 알려줘
```

## Mock API 구현 프롬프트

```
외부 연동 API가 아직 없으므로 Mock API를 먼저 구현해줘.
- 실제 API와 동일한 인터페이스 (요청/응답 형식)
- 나중에 실제 API로 교체가 쉽도록 분리된 모듈로 구현
- 테스트용 샘플 데이터 포함
```

## 커밋 컨벤션

```
feat: 새 기능 추가
fix: 버그 수정
refactor: 리팩토링
style: UI/스타일 변경
docs: 문서 수정
chore: 설정/환경 변경
test: 테스트 추가/수정
```
